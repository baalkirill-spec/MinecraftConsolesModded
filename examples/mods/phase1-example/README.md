# Example Phase-1 Folder Mod

This folder demonstrates the currently supported runtime-friendly structure.

## Included in this example

- `mod.json` metadata.
- `assets/minecraft/textures/...` path for runtime asset overrides.
- `data/examplemod/mechanics/...` sample lightweight data definition.

## Notes

- Replace placeholder files with real textures/data used by your mod.
- Zip mods remain metadata-only in the current phase-1 implementation.
