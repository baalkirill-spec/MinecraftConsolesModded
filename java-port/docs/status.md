# Java Port Status

## Ready now
- runnable desktop window via LibGDX
- basic game loop
- title menu
- options persistence
- FPS overlay
- Java phase-1 mod scanning
- mods browser screen

## Not implemented yet
- gameplay/world simulation
- renderer parity with C++ engine
- custom skin runtime
- multiplayer/networking
- low-level rendering backend parity
- asset override application into a real Java renderer

## Honest limitation
Этот Java-port пока является **архитектурной заготовкой**, а не полноценной игровой Java-версией.
